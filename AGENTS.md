This project "lobg" is a personal blog built on a fork of AstroPaper.
The content of the site will contain mostly technical information on my personal projects.

Most of them can be found publically on my GitHub account https://github.com/theme22/
It is not a serious blog, but rather a playful area to talk about my passions.

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
